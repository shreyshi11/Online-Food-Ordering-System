# 🍔 Online Food Ordering System

A Java-based project implementing the core functionalities of an Online Food Ordering System. This project is part of my learning journey in Java and Object-Oriented Programming and is currently under development.

---

## ✨ Features

- User Registration & Login
- Food Menu Management
- Order Processing
- Bill Generation
- Core Java-based Functionality

---

## 🛠️ Tech Stack

- Java
- Object-Oriented Programming (OOP)
